# Project brief

## The goal

Tiny Sums adds numbers correctly and reliably. It stays a small, dependable example with no real data, so people can use it to practise how changes are reviewed and merged into a protected main branch.

## Milestones, in order

### 1. Adding numbers stays right — not done

**Id:** keep-sums-right

**Done when:** Adding several numbers gives their total, for example 1, 2 and 3 gives 6. Adding no numbers at all gives 0. Adding negative numbers and decimals gives the correct total.

**Checks:**
- a-total: Adding several numbers gives their total, for example 1, 2 and 3 gives 6.
- a-empty: Adding no numbers at all gives 0.
- a-signs: Adding negative numbers and decimals gives the correct total.

### 2. Try it — not done

**Id:** try-it

**Done when:** Adding a few numbers of your own gives totals that look right to you. The README says in plain words what Tiny Sums does and that it holds no real data. Nothing in the project asks for payment, sign-in or personal details.

**Checks:**
- b-own: Adding a few numbers of your own gives totals that look right to you. [You check it]
- b-readme: The README says in plain words what Tiny Sums does and that it holds no real data.
- b-nothing: Nothing in the project asks for payment, sign-in or personal details.

### 3. A single number stays itself — not done

**Id:** single-number

**Done when:** Giving the existing sum function just 7 returns 7. Giving the existing sum function just 0 returns 0. Giving the existing sum function just -2.5 returns -2.5.

**Checks:**
- single-number-positive: Giving the existing sum function just 7 returns 7.
- single-number-zero: Giving the existing sum function just 0 returns 0.
- single-number-try-it: Giving the existing sum function just -2.5 returns -2.5.
